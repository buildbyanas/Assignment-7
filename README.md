## 📖 প্রজেক্ট পরিচিতি

**Bazar-Dor** বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর সহজে জানা ও তুলনা করার জন্য তৈরি একটি বাংলা ওয়েব অ্যাপ্লিকেশন।

এই ওয়েবসাইটের মাধ্যমে ব্যবহারকারীরা বিভিন্ন পণ্যের বর্তমান দাম, আগের দামের তথ্য এবং বিভিন্ন বাজারের মূল্যসীমা দেখতে পারেন। এর মূল উদ্দেশ্য হলো বাজারে যাওয়ার আগে পণ্যের দাম সম্পর্কে ধারণা দেওয়া এবং কেনাকাটার পরিকল্পনা করতে সাহায্য করা।

## 🎯 প্রজেক্টের উদ্দেশ্য

- নিত্যপ্রয়োজনীয় পণ্যের বাজারদর সহজে উপস্থাপন করা।
- বিভিন্ন বাজারের দামের পার্থক্য বোঝার সুযোগ তৈরি করা।
- আগের দামের সঙ্গে বর্তমান দামের তুলনা সহজ করা।
- ব্যবহারকারীদের সচেতনভাবে কেনাকাটার পরিকল্পনায় সহায়তা করা।
- বাংলা ভাষায় সহজ ও ব্যবহারবান্ধব অভিজ্ঞতা দেওয়া।

## 💚 ব্যবহারকারীদের সুযোগ-সুবিধা

### 🛍️ ১. কেনাকাটার আগে বাজারদর জানা

বাজারে যাওয়ার আগে প্রয়োজনীয় পণ্যের দাম দেখে নেওয়া যায়। এতে বাজার সম্পর্কে প্রাথমিক ধারণা তৈরি হয় এবং কেনাকাটার পরিকল্পনা করা সহজ হয়।

### 🏪 ২. বিভিন্ন বাজারের দাম তুলনা

একটি পণ্যের বিভিন্ন বাজারের সর্বনিম্ন ও সর্বোচ্চ দাম দেখা যায়। ফলে কোন বাজারে দাম তুলনামূলক কম বা বেশি, তা বুঝতে সুবিধা হয়।

### 📉 ৩. দামের পরিবর্তন বোঝা

আজকের দামের সঙ্গে গতকাল, গত সপ্তাহ ও গত মাসের দাম তুলনা করে পণ্যের মূল্য বেড়েছে নাকি কমেছে, সে সম্পর্কে ধারণা পাওয়া যায়।

### 🧮 ৪. সর্বনিম্ন, সর্বোচ্চ ও গড় দাম দেখা

পণ্যের দামের সারসংক্ষেপ থেকে সর্বনিম্ন, সর্বোচ্চ এবং বিভিন্ন বাজারের গড় মূল্য দেখা যায়। এতে দামের পার্থক্য বোঝা সহজ হয়।

### 🗂️ ৫. ক্যাটাগরি অনুযায়ী পণ্য খোঁজা

নির্দিষ্ট ক্যাটাগরি থেকে প্রয়োজনীয় পণ্য খুঁজে পাওয়া যায়। পণ্যের তালিকা দাম অনুযায়ী সাজিয়ে তুলনা করাও সহজ হয়।

### 📱 ৬. মোবাইল ও কম্পিউটারে ব্যবহার

Responsive Design-এর কারণে মোবাইল, ট্যাবলেট ও কম্পিউটার থেকে ওয়েবসাইট ব্যবহার করা যায়।

### 👤 ৭. নিজের অ্যাকাউন্ট পরিচালনা

ব্যবহারকারীরা নতুন অ্যাকাউন্ট তৈরি করতে, ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করতে অথবা Google ও GitHub-এর মাধ্যমে সাইন ইন করতে পারেন। প্রোফাইল থেকে নিজের নাম আপডেট ও সাইন আউট করা যায়।

### 🌟 Bazar-Dor কেন ব্যবহার করবেন?

- **এক জায়গায় তথ্য:** পণ্যের বর্তমান ও আগের দামের তথ্য দেখা।
- **সহজ তুলনা:** বাজারভেদে দামের পার্থক্য বোঝা।
- **সচেতন পরিকল্পনা:** কেনাকাটার আগে সম্ভাব্য খরচ সম্পর্কে ধারণা পাওয়া।
- **সময় সাশ্রয়:** অনলাইনে প্রয়োজনীয় তথ্য দেখা।
- **বাংলা ইন্টারফেস:** সহজ ভাষায় তথ্য বোঝা।

> **দাম সম্পর্কে সতর্কতা:** ওয়েবসাইটে প্রদর্শিত মূল্য API-তে থাকা তথ্যের ওপর নির্ভরশীল। বাস্তব বাজারে স্থান, সময়, পণ্যের মান ও সরবরাহ অনুযায়ী দাম পরিবর্তিত হতে পারে। তাই প্রদর্শিত দামকে নিশ্চিত বিক্রয়মূল্য হিসেবে বিবেচনা না করে বাজারে যাচাই করে নেওয়া উচিত।

## 💻 Installation ও Setup

### ১. Repository ক্লোন করুন

```bash
git clone https://github.com/buildbyanas/Assignment-7.git
cd Assignment-7
```

### ২. Dependencies ইনস্টল করুন

```bash
npm install
```

### ৩. `.env.local` ফাইল তৈরি করুন

প্রজেক্টের root directory-তে `.env.local` ফাইল তৈরি করে নিচের variable-গুলো যোগ করুন।

```env
NEXT_PUBLIC_API_BASE_URL=https://openapi.programming-hero.com/api/bazardor

BETTER_AUTH_SECRET=replace_with_a_secure_random_secret
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_BETTER_AUTH_URL=http://localhost:3000

MONGODB_URI=mongodb+srv://USERNAME:PASSWORD@YOUR_CLUSTER.mongodb.net/bazar_dor?retryWrites=true&w=majority

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
```

নিজের আসল credential দিয়ে placeholder-গুলো প্রতিস্থাপন করুন।

### ৪. Development Server চালু করুন

```bash
npm run dev
```

ব্রাউজারে খুলুন:

```text
http://localhost:3000
```

## 🔐 Authentication ও OAuth

Better Auth ব্যবহার করে নিচের সুবিধাগুলো কনফিগার করা হয়েছে:

- Email ও Password দিয়ে Sign Up এবং Sign In
- Google OAuth Login
- GitHub OAuth Login
- Profile থেকে নাম আপডেট
- Sign Out
- Product Details পেজে server-side session check

### OAuth Callback URLs

**Local Development**

```text
Google: http://localhost:3000/api/auth/callback/google
GitHub: http://localhost:3000/api/auth/callback/github
```

**Production**

```text
Google: https://assignment-7-taupe-nine.vercel.app/api/auth/callback/google
GitHub: https://assignment-7-taupe-nine.vercel.app/api/auth/callback/github
```

Google ও GitHub developer settings-এ callback URL সঠিকভাবে কনফিগার করতে হবে। Google app Testing mode-এ থাকলে অনুমোদিত test user যোগ করতে হতে পারে।
